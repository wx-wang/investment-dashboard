## 内容清单
- index.html、dashboard.html：同一页面的入口与离线副本，全部样式和交互代码内嵌。

- SHA256SUMS：除自身以外的公开包文件校验值。

保留：公开券商文章的三条短摘要、三条公开事件摘要、明确标注的研究推断、250日等区间控件、行业/相关性/风险空数据框架。
